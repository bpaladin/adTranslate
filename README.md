# PDF Translator v1.0

Параллельный перевод PDF-документов на другой язык с сохранением форматирования, изображений и таблиц. Поддерживает режим перевода и генерации рефератов.

## Установка

```bash
pip install -r requirements.txt
```

Зависимости: `pymupdf`, `openai`, `requests`, `jinja2`, `tqdm`, `markdown`, `cachetools`.

## Быстрый старт

```bash
# Перевод через Google (без ключа) → файл paper_translate.html
python main.py paper.pdf

# Перевод через OpenRouter
python main.py paper.pdf -t openrouter

# Локальный переводчик (llama.cpp)
python main.py paper.pdf -t llama

# Реферат статьи → файл paper_summary.html
python main.py paper.pdf --summary
```

Выходной HTML-файл создаётся автоматически рядом с входным: `*_translate.html` (перевод) или `*_summary.html` (реферат).

## CLI

```
python main.py <input.pdf> [опции]
```

| Опция | По умолчанию | Значение |
|---|---|---|
| `--version` | — | Показать версию и выйти |
| `-l, --lang` | `ru` | Целевой язык перевода |
| `-t, --translator` | `google` | Переводчик: `google`, `llama`, `openrouter` |
| `--llama-url` | `http://localhost:8080/v1` | URL llama.cpp сервера |
| `--llama-model` | — | Ожидаемое имя модели на сервере |
| `--no-auto-find` | — | Отключить авто-поиск llama-сервера |
| `--summary` | — | Режим реферата |
| `--summary-translator` | `llama` | Генератор реферата: `google`, `llama`, `openrouter` |
| `--summary-lang-translator` | `google` | Переводчик готового реферата |
| `--workers` | `min(8, cpu*2)` | Число параллельных воркеров |
| `--task-timeout` | `600` | Таймаут на весь перевод (сек) |
| `--refine` | — | Итеративный рефайн перевода (для локальных LLM) |
| `--dark-html` | вкл | Тёмная тема HTML |
| `--light-html` | — | Светлая тема HTML |
| `-q, --quiet` | — | Тихий режим |
| `-v, --verbose` | — | Подробный вывод (DEBUG) |

### Переменные окружения

```
OPENROUTER_API_KEY    API-ключ для OpenRouter
OPENAI_API_KEY        Альтернативный ключ (fallback для OpenRouter)
```

Ключи можно положить в файл `keys.env` или `.env` рядом со скриптом — они загрузятся автоматически.

## Переводчики

| Имя | Прокси | Описание |
|---|---|---|
| `google` | не нужен | Google Translate API (бесплатный, без ключа) |
| `openrouter` | опционально | OpenRouter — доступ к множеству моделей |
| `llama` | не нужен | Локальный llama.cpp сервер |

- **OpenRouter:** при старте запрашивается список моделей, выбираются бесплатные, при переполнении лимита (429) модель временно отключается.
- **llama.cpp:** автоматически находит запущенные серверы (`pgrep llama-server`), при `--llama-model` ищет модель по имени, иначе берёт первую доступную.
- **Кэш:** переводы и глоссарии кэшируются в JSON (`translation_cache.json`).

## Режимы работы

### Translate (по умолчанию)

Полный перевод PDF-документа с сохранением:
- Форматирования (абзацы, заголовки, списки)
- Изображений и подписей к ним (включая векторные фигуры, которые отрисовываются из PDF)
- Таблиц (структура сохраняется, ячейки переводятся LLM)
- Списка литературы (не переводится, остаётся в оригинале)

Параллельный перевод через `ThreadPoolExecutor` с защитой ссылок на литературу (`[[REFn]]`), номерных цитат и глоссарием терминов.

### Summary (реферат)

Генерация структурированного реферата научной статьи:

```bash
# Реферат через llama (по умолчанию)
python main.py paper.pdf --summary

# Реферат через OpenRouter, перевод через Google
python main.py paper.pdf -t openrouter --summary --summary-lang-translator google
```

Формат реферата:
```
КРАТКОЕ СОДЕРЖАНИЕ: 4-5 предложений
КЛЮЧЕВЫЕ НАХОДКИ: список
СИЛЬНЫЕ СТОРОНЫ: список
СЛАБЫЕ СТОРОНЫ: список
```

Режим работает в два этапа:
1. LLM генерирует реферат **на английском** (чанки по 6000 символов)
2. Полученный реферат переводится на целевой язык

## HTML-отчёт

- Тёмная и светлая темы
- **Сворачиваемые блоки «Страница N»** (клик по заголовку страницы)
- Содержание (TOC) по заголовкам с якорями
- Кнопки «Показать/Скрыть все оригиналы»
- Подсветка ссылок на литературу, клик по изображению — увеличение (lightbox)
- Таблицы рендерятся как HTML-таблицы, фигуры — как изображения с подписями

## Батч-обработка

```bash
# Пакетный перевод всех PDF в каталоге
./batch_translator.sh

# Пакетная генерация рефератов
./batch_summary.sh [КАТАЛОГ] [РЕЖИМ] [МОДЕЛЬ]
```
